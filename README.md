# Md. Hasibul Hossain — portfolio

Resume-driven portfolio built with Next.js, React and TypeScript. Content is sourced from `resume.pdf`; the supplied introduction video is served from `public/hero/intro.mp4`.

## Run

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Sections

Hero, About, Skills, Selected work, Experience, Research and Contact. Certifications and achievement sections were omitted because the résumé does not provide certification records or platform achievement totals.
